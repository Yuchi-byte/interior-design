Image as context: the reference photo as FLUX.1-Redux tokens in the FMRG prior

Study fmrg_redux in framework 0002_geometric_guidance · 2026-08-14 rerun, local RTX 5090 · commit fab13673 · 2 scenes × 6 arms, seed 0, eta 5.0 guided (owner reset from 15), start_sigma 0.9 (effective 0.9441), Redux scales 0.3, 1 · shell incl. windowpane/door/curtain/rug, recorded in results.json · eta-15 run preserved as results_eta15.json

Verdict

Does image-as-context keep the layout better than text alone? In the mean, yes — unguided depth error falls from 0.888 (A) to 0.150 at scale 0.3 (R1) and 0.041 at 1.0 (R3) — but not reliably: on scandi_living_room R1 is worse than A (+43%), inventing a sofa where the sideboard was while pulling the old sofa back. The unguided arms are pixel-identical to the eta-15 run (no eta dependence at seed 0), so this half of the picture is unchanged: what the tokens keep is the whole room, furniture included, not the shell.

Does the image drown the text at full scale? Yes, unchanged. R3/R4 are near-copies of the reference photo in both scenes — the renovation instruction is inert. The kitchen's adherence collapses to 58% of A's; the scandi scene's adherence stays high only because the original room already matches the eval text. At 0.3 the text is audible but still losing: the kitchen keeps green-vintage styling instead of matte-black industrial (adherence 61% of A).

Is the depth reward still additive at eta 5? Yes — every guided arm still lands below its unguided twin (kitchen C 0.431 vs A 1.616, R2 0.0027 vs R1 0.070, R4 0.0011 vs R3 0.0040; scandi C 0.032 vs A 0.161, R2 0.054 vs R1 0.230) — but the hold is 2–83× looser than at eta 15, and the slack is not spent evenly (see below).

The eta-15 headline is broken on the hard scene. At eta 15, text-only guided C was the one arm that renovated and held depth. At eta 5, C still does both on scandi (depth 0.032, −80% vs A, visibly renovated) — but on the kitchen C's depth error is 0.431: the render is still A's loft galley, nudged toward the reference, not the reference room recovered. At eta 5 no arm renovates the kitchen and holds its depth at once: C renovates but loses the room; R2/R4 hold depth by pulling the old kitchen back. The depth reward remains the better geometry channel than Redux (it adds on top at every scale), but at this strength it is not sufficient on the scene whose prior fights it hardest.

Then vs now: the eta-15 run against this one

Two settings nominally changed between the runs' commits — guidance eta 15 → 5.0 (59d7963) and curtain + rug joining the reward shell (bf1e094; windowpane and door were already in it) — so per-arm deltas against results_eta15.json would ordinarily be confounded, and within-run comparisons are the trustworthy ones. The forensics, however, say the confound largely isn't there: the eta-15 run's reference-side coverages are bit-identical to this run's (scandi A own-shell 0.8018761233515762 in both, kitchen 0.7156526664083227 in both) despite the scandi photo segmenting 10.8% of its frame as curtain, and bf1e094 was committed at 21:34 — four minutes after that run started at 21:30 — so its working tree evidently already carried the enlarged shell. Every then-vs-now delta below is therefore effectively eta alone. That reading rests on inferring an uncommitted working tree, so the within-run comparisons remain the ones to trust; the shell's own effect is measured directly, at fixed eta, in the ablation underneath.

Confounds and what checks them

  • Depth won by copying, now beating guidance. At eta 15, R3 merely matched guided C on the kitchen; at eta 5 it beats C outright (0.0040 vs 0.4309) — by reproducing the room. The adherence collapse (58% of A) plus the side-by-side renders expose it; depth never travels alone.
  • The scandi adherence blind spot. The eval text is 'scandinavian living room' and the reference already is one, so a copy scores high adherence (R3: 116%, R4: 118% of A — R4 now tops the scene's adherence table while renovating nothing). Only the visual check catches the un-renovated blue sofa. Scene pairs whose target style differs from the source (the kitchen) are the informative ones for this axis.
  • Shell coverage reads higher on image arms (82–87% vs 76% own shell): a render that mirrors the photo re-exposes the photo's shell. More shell is not more renovation — it is consistent with copying, as the study's design notes anticipate.
  • One seed, two scenes. Fast-iteration setting; the directional findings (drowning at 1.0, furniture pull-back at both scales, additive reward, the eta-5 collapse of text-only C on the hard scene) are consistent across both scenes, but the magnitudes are not population estimates — and the C collapse in particular is one (scene, seed) and deserves a second seed before it drives an eta decision.

Methods

  • Injection: the photo through FLUX.1-Redux-dev (SigLIP so400m-patch14-384 → Redux adapter) gives 729 tokens in the T5's 4096-wide space, appended after the 512 text tokens: cat([text_embeds, scale · image_tokens], dim=1). The scale multiplies the image tokens alone (diffusers' prompt_embeds_scale scales the whole row, text included). Pooled embedding stays the text CLIP pooled, as diffusers' Redux pipeline keeps it. The combined context is cached and selected exactly like a text prompt; the vendored sampler sizes text_ids off prompt_embeds.shape[1], so no vendored edit. Code: roomgen_guide/adapters/fmrg_flux.py (encode_redux_image_tokens, register_image_context_prompt).
  • Sampler: FMRG FLUX flow map (fmrgj_nfe100 grid: 208 grid steps, early stop 51, 51 walked), start_sigma 0.9 pre-shift (effective 0.9441 at 512²), text guidance 3.5, endpoint-reuse stepping, cheap pullback (FMRG-E). Guided arms: AnnealedSignTilt eta 5.0 (owner reset from 15, 59d7963), 1 iteration. Seed 0, explicit generators end to end.
  • Reward shell: ARCHITECTURAL_CLASSES incl. windowpane 8, door 14, curtain 18, rug 28 (50f3ec9/bf1e094); the class table the run actually scored under is now recorded in results.json (shell_classes, alongside a top-level eta).
  • Prompts: exact texts from the context study's conf/context.yaml — the style description (A, C) and the renovation instruction (R1–R4), whose “this room” now binds to actual image tokens. Eval text = the neutral style description, all arms.
  • Versions: torch 2.13.0+cu132, diffusers 0.39.0 (FluxPriorReduxPipeline; vendored FMRG pins 0.34, no resolver moves needed), FLUX.1-Redux-dev snapshot c95859fb (941 MB: 857 MB SigLIP + 129 MB adapter) in the repo HF cache.
  • VRAM: Redux caching phase peak 1.00 GiB (before the transformer loads); walk-phase peak 28.17 GiB on NVIDIA GeForce RTX 5090. Study wall-clock 2 min 52 s.

The Redux scale dial: the furnished photo against its own renovation prompt

Study fmrg_redux in framework 0002_geometric_guidance · 2026-08-15, local RTX 5090 · commit d59815e3 · 5 scenes × 10 arms (Redux scale ∈ {0, 0.1, 0.3, 0.7, 1} × ±depth), seed 0, eta 5, start_sigma 0.9 (effective 0.9441) · depth reference = the stripped empty room (stage zero, 0003's strip) · Redux encodes the furnished photo · every prompt carries a per-scene removal instruction · prior runs preserved as results_v2.json / results_eta15.json · walk peak 28.2 GiB

Verdict

The dial has two regimes, and the knee sits between 0.3 and 0.7. At scale 0 the renovation prompt alone loses the room: mean unguided depth error 2.43, and three of five scenes render a different room outright. By 0.3 the image tokens have pulled the room back (0.63 unguided, −74% vs text-only) — same viewpoint, same walls, same window — and at 0.7–1.0 the arm is visibly copying: render-to-photo similarity climbs to 0.88–0.89, the original furniture returns piece by piece (the scandi shell chair, the hotel's glass coffee table, the loft's desk with its iMac — each an object the prompt explicitly asked to remove), and adherence to the new style sits at its floor (mean 0.19 vs 0.26 text-only; 50–59% of baseline on the two scenes whose style change is largest). PickScore falls monotonically along the dial (20.9 → 19.2): the preference proxy consistently likes free renovations more than copies.

Is there a scale that informs without dominating? Partially. 0.1 keeps the text clearly audible (adherence 84–92% of baseline per scene, removal mostly obeyed) but anchors the layout only weakly (mean unguided depth 1.66; the loft is still lost). 0.3 anchors the room on four of five scenes, but the text is already losing there — the kitchen's dark table is back (8.9% of frame), the hotel's tables re-grow (13.8%), and the industrial restyle the kitchen prompt asks for has visibly diluted. There is no scale at which both the layout snaps in and a large style change fully survives.

The clean split is: let Redux carry appearance and layout binding at 0.3, and let the depth reward carry geometry. Depth guidance stacks on top of every scale — a further 2–4× depth-error reduction wherever the dial sits (mean 0.63 → 0.21 at 0.3; best absolute 0.178 at 0.7 guided) — and it costs 0–5% adherence where the image tokens cost 25–45%. And because the reference is the stripped empty room, the depth reward never defends the removed object's mass: guided and unguided arms remove (or fail to remove) the object together at every scale — the one apparent exception is a segmentation artifact, not a depth effect (see the loft).

Reading the curve: the text mostly wins at scales 0–0.1, the contest is live at 0.3 (the kitchen table returns at 8.9%, the hotel's table family re-grows to 13.8%), and at 0.7–1.0 the render is a near-copy, so whatever stood in the photo returns wherever the class family can see it. The metric is non-monotone where the eye is not, for two reasons worth naming. First, the family under-counts copies: the kitchen at scale 1 visibly restores the teal island and its chairs, but EoMT calls an island "kitchen island", which is not in the table family — 0.0% compliance for a render that plainly failed the instruction (the render row below is the evidence). Second, it over-counts style furniture: the loft's scale-0 guided arm scores 13.4% because the "low wooden platform bed" the style text asks for is read as table/desk by the segmenter — the empty-room reference contains no desk, so this is a misread platform, not the depth reward resurrecting one. The per-scene render rows, not this table alone, are the honest read; the table says where to look.

Two priors also add the object back unprompted at scale 0: the hotel and lakehouse text-only arms furnish their invented rooms with a coffee table and armchairs respectively — FLUX's idea of a living room includes the very furniture the instruction removes, which bounds what "remove the X" can do before any image tokens enter.

Confounds and honest limits

  • The kitchen's reference is not empty. The strip left 29.2% of the cut region as recognisable contents (cabinets, fridge, stove — visible in its empty-room image above), so that scene's depth errors are scored against a part-furnished reference. Flagged rather than excluded, per the owner's instruction; its dial behaviour matches the clean scenes.
  • The removal-compliance metric is a class-family count, not an object tracker. It cannot see that the kitchen's returned island is the same failed removal (island ≠ table to ADE20K), and it counts the loft's prompt-requested platform bed as a desk. It quantifies the trend; the renders adjudicate individual cells.
  • Adherence is half-blind where the photo already matches the style (scandi, and partially hotel): a copy of the photo still scores near the baseline. Image similarity is the disambiguator — 0.88+ with flat adherence is the copying regime, and both are reported per arm.
  • The lakehouse strip changed the floor material (dark carpet → pale slab), so its empty-room depth is not exactly the room's depth; its reconstruction floor (0.00167) is the largest in the study and its absolute depth errors are inflated by the mismatch. Cross-scale comparisons within the scene remain valid.
  • One seed, five scenes. The dial's shape (two regimes, knee at 0.3–0.7) is consistent across all five scenes, but every per-cell number is a single draw; the loft's scale-0 degeneration in particular looks seed-sensitive.
  • The Redux context costs wall clock: +729 image tokens lengthen the T5 context, and walks go from 8.2s (scale 0) to ~12.7s unguided / 13.1s to ~17.8s guided — a +54%/+36% cost that scales with token count, not with the scale multiplier.
  • Depth errors at scale 0 are dominated by outright room loss (different architecture), not by furniture drift — they measure "wrong room", not "wrong renovation", which is exactly what the image tokens then fix.

Methods

  • Sampler: FMRG two-time flow map on FLUX.1-dev (512², bf16), grid 208, early stop 51, 51 walked steps, embedded guidance 3.5; every arm inits from the furnished photo renoised to start_sigma 0.9 (effective 0.9441 after FLUX's mu-shift), one shared torch.Generator seed 0 per walk.
  • Image context: FLUX.1-Redux-dev (SigLIP + adapter) tokens of the furnished photo appended to the T5 context; the configured scale multiplies the image tokens alone, text embeds untouched; scale 0 selects the plain text entry, never a zero-scaled copy. Encoders loaded before and freed ahead of the transformer.
  • Stage zero strip: 0003's machinery verbatim — EoMT contents mask (dilation 8px), SD-inpaint (5 passes max, 40 steps, fill 0.85, cfg 12, float16), contents-blocklist acceptance; photo composited back outside the mask.
  • Depth reward and eval: Depth Anything V2 affine-invariant disparity, every comparison through align_scale_shift (positive scale floor); reference = the empty room's shell depth; guided arms descend it with FMRG's annealed sign tilt at eta 5 (unguided arms eta 0 on the identical trajectory); eval on the one common mask per scene (empty shell ∩ every arm's own re-segmented shell), residual maps on the baseline arm's colour scale. Shell = bannister, ceiling, column, curtain, door, floor, railing, rug, stairs, stairway, step, wall, windowpane.
  • Judges (loaded one at a time after all walks): CLIP ViT-L/14 adherence vs the scene's neutral style text (never the arm's own prompt, never the image); CLIP ViT-L/14 render-to-photo image similarity; PickScore v1 (CLIP-H) vs the same neutral text. Removal compliance = share of frame EoMT assigns to the scene's removal class family, photo share as baseline. None of these is a checkpoint any arm descends.
  • Records: numbers in outputs/0002_fmrg_redux/results.json; the prior furnished-reference study is preserved beside it (results_v2.json, eta-15 run results_eta15.json).
